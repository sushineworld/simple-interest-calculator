# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest earned or paid on a principal amount over a specified period at a given annual interest rate.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual interest rate in percentage.
- **Time (T):** The time period in years.

## Example

Suppose:
- Principal = 1000
- Annual Interest Rate = 5%
- Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

**Simple Interest = 100**

Total Amount = Principal + Simple Interest

**Total Amount = 1100**

## Features
- Calculates simple interest using the standard formula.
- Accepts principal, annual interest rate, and time.
- Displays the calculated interest and total amount.

## Technologies
The calculator can be implemented using Python, C++, Java, or JavaScript.

## How to Use
1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest using the formula.
5. Add the interest to the principal to obtain the total amount.
